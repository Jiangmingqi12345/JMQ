# 毕业设计管理系统前端开发计划

## 一、项目架构

### 1. 技术栈
- **核心框架**：Vue 3 + Element Plus + Vite
- **路由管理**：Vue Router 4
- **状态管理**：Pinia
- **HTTP客户端**：Axios
- **UI组件库**：Element Plus
- **工具库**：Day.js

### 2. 目录结构
```
├── src
│   ├── assets/          # 静态资源
│   ├── components/      # 公共组件
│   ├── views/           # 页面组件
│   │   ├── login/       # 登录页
│   │   ├── layout/      # 布局组件
│   │   ├── user/        # 用户管理
│   │   ├── project/     # 项目管理
│   │   ├── selection/   # 选题管理
│   │   └── thesis/      # 论文管理
│   ├── router/          # 路由配置
│   ├── stores/          # 状态管理
│   ├── utils/           # 工具函数
│   │   ├── axios.js     # Axios配置
│   │   └── auth.js      # 权限管理
│   ├── App.vue          # 根组件
│   └── main.js          # 入口文件
└── vite.config.js       # Vite配置
```

## 四、API对接

### 1. 后端接口设计
- 遵循RESTful API规范
- 使用JSON格式数据
- 统一响应格式
- 错误处理机制

### 2. 接口列表
| 模块 | 接口 | 方法 | 功能 |
|------|------|------|------|
| 用户管理 | /api/user/login | POST | 用户登录 |
| 用户管理 | /api/user/register | POST | 用户注册 |
| 用户管理 | /api/user/list | GET | 获取用户列表 |
| 项目管理 | /api/project/list | GET | 获取项目列表 |
| 项目管理 | /api/project/add | POST | 添加项目 |
| 选题管理 | /api/selection/apply | POST | 申请选题 |
| 选题管理 | /api/selection/approve | POST | 审核选题 |
| 论文管理 | /api/thesis/upload | POST | 上传论文 |
| 论文管理 | /api/thesis/review | POST | 评审论文 |
