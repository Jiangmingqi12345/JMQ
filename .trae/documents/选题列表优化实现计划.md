# 选题列表优化实现计划

## 需求分析
根据用户需求，需要对选题列表进行以下优化：
1. 显示项目名称和学生名
2. 保留学生ID，去掉ID和项目ID
3. 开放查看功能
4. 选择时间以年月日的形式展现

## 实现步骤

### 1. 扩展Selection实体
- 添加`projectName`和`studentName`字段，用于存储项目名称和学生名

### 2. 修改后端查询逻辑
- 修改`SelectionDao.xml`中的查询SQL，关联查询项目表和用户表
- 在`findAll`、`findAllByStatus`等方法中填充`projectName`和`studentName`字段

### 3. 修改前端SelectionListView.vue
- 移除ID和项目ID列
- 添加项目名称和学生名列
- 保留学生ID列
- 修改选择时间的显示格式为年月日
- 实现查看功能

## 详细实现

### 1. 扩展Selection实体
在`Selection.java`中添加以下字段：
```java
private String projectName;
private String studentName;
// 添加getters和setters
```

### 2. 修改SelectionDao.xml
- 修改查询SQL，关联查询项目表和用户表
- 例如，在`findAll`方法中：
```xml
<select id="findAll" resultMap="SelectionMap">
    SELECT s.*, p.title AS projectName, u.name AS studentName 
    FROM selection s 
    JOIN project p ON s.project_id = p.id 
    JOIN user u ON s.student_id = u.id
</select>
```

### 3. 修改前端SelectionListView.vue
- 调整表格列：
```vue
<el-table :data="selectionList" stripe style="width: 100%" v-loading="loading">
    <el-table-column prop="studentId" label="学生ID" width="120"></el-table-column>
    <el-table-column prop="studentName" label="学生姓名" width="150"></el-table-column>
    <el-table-column prop="projectName" label="项目名称" min-width="200"></el-table-column>
    <el-table-column prop="status" label="状态" width="120">
        <template #default="scope">
            <el-tag :type="getStatusColor(scope.row.status)">
                {{ getStatusText(scope.row.status) }}
            </el-tag>
        </template>
    </el-table-column>
    <el-table-column prop="selectTime" label="选择时间" width="150">
        <template #default="scope">
            {{ formatDate(scope.row.selectTime) }}
        </template>
    </el-table-column>
    <el-table-column label="操作" width="200" align="center">
        <template #default="scope">
            <el-button v-if="scope.row.status === 'PENDING'" type="success" size="small" @click="handleApprove(scope.row.id)">审核</el-button>
            <el-button type="info" size="small" @click="handleView(scope.row.id)">查看</el-button>
        </template>
    </el-table-column>
</el-table>
```

- 添加日期格式化方法：
```javascript
const formatDate = (date) => {
    if (!date) return '';
    const d = new Date(date);
    return `${d.getFullYear()}-${String(d.getMonth() + 1).padStart(2, '0')}-${String(d.getDate()).padStart(2, '0')}`;
}
```

- 实现查看功能：
```javascript
const handleView = (id) => {
    router.push(`/selection/detail/${id}`);
}
```

- 选择时间显示格式为：YYYY-MM-DD
- 查看按钮功能开放，点击跳转到详情页
