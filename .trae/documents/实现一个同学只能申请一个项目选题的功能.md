# 实现一个同学只能申请一个项目选题的功能

## 问题分析
当前系统允许学生同时申请多个项目选题，即使其中一个已经被老师批准，学生仍然可以申请其他项目。这不符合实际的毕业设计管理需求，需要修复。

## 实现方案

### 1. 数据库查询逻辑
- 在`SelectionDao.java`中添加方法，用于查询学生是否已有被批准或待审核的选题记录
- 在`SelectionDao.xml`中添加对应的SQL语句

### 2. 业务逻辑处理
- 在`SelectionServiceImpl.java`的`apply`方法中添加检查逻辑
- 当学生申请选题时，检查该学生是否已有：
  - 已批准（APPROVED）的选题记录
  - 待审核（PENDING）的选题记录
- 如果存在上述情况，拒绝新的申请

### 3. 前端提示优化
- 在选题申请页面添加提示，告知学生只能申请一个项目
- 当学生已有选题时，前端应禁用申请功能或给出明确提示

## 具体实现步骤

### 1. 修改`SelectionDao.java`
添加以下方法：
```java
/**
 * 查询学生是否有已批准的选题记录
 * @param studentId 学生ID
 * @return 已批准的选题记录，如果没有返回null
 */
Selection findApprovedByStudent(@Param("studentId") Integer studentId);

/**
 * 查询学生是否有待审核的选题记录
 * @param studentId 学生ID
 * @return 待审核的选题记录列表
 */
List<Selection> findPendingByStudent(@Param("studentId") Integer studentId);
```

### 2. 修改`SelectionDao.xml`
添加对应的SQL语句：
```xml
<!-- 查询学生已批准的选题记录 -->
<select id="findApprovedByStudent" resultMap="SelectionMap">
    SELECT s.*, p.title AS project_name, u.name AS student_name 
    FROM selection s 
    LEFT JOIN project p ON s.project_id = p.id 
    LEFT JOIN user_account u ON s.student_id = u.id 
    WHERE s.student_id=#{studentId} AND s.status='APPROVED'<!-- 条件：学生ID和状态为已批准 -->
</select>

<!-- 查询学生待审核的选题记录 -->
<select id="findPendingByStudent" resultMap="SelectionMap">
    SELECT s.*, p.title AS project_name, u.name AS student_name 
    FROM selection s 
    LEFT JOIN project p ON s.project_id = p.id 
    LEFT JOIN user_account u ON s.student_id = u.id 
    WHERE s.student_id=#{studentId} AND s.status='PENDING'<!-- 条件：学生ID和状态为待审核 -->
</select>
```

### 3. 修改`SelectionServiceImpl.java`
在`apply`方法中添加检查逻辑：
```java
// 检查学生是否已有被批准的选题
if (selectionDao.findApprovedByStudent(studentId) != null) {
    return false; // 已有被批准的选题，无法再次申请
}

// 检查学生是否有待审核的选题
List<Selection> pendingSelections = selectionDao.findPendingByStudent(studentId);
if (!pendingSelections.isEmpty()) {
    return false; // 有待审核的选题，无法再次申请
}
```

### 4. 前端优化
在`SelectionApplyView.vue`中添加检查逻辑：
- 在组件挂载时检查学生是否已有选题
- 如果已有选题，给出提示并禁用申请功能

## 预期效果
- 学生只能申请一个项目选题
- 如果学生已有被批准的选题，无法再次申请
- 如果学生有待审核的选题，无法再次申请
- 前端会给出明确的提示信息

## 业务流程
1. 学生进入选题申请页面
2. 系统检查该学生是否已有选题记录
3. 如果已有：
   - 显示提示信息："您已有选题，无法再次申请"
   - 禁用申请按钮
4. 如果没有：
   - 正常显示申请表单
   - 允许学生申请选题
5. 提交申请时，后端再次检查，确保数据一致性

## 技术要点
- 使用MyBatis进行数据库查询
- 添加业务逻辑检查，确保数据一致性
- 优化前端用户体验，给出明确提示
- 保持前后端数据一致性
